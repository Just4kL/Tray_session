# Tray Session - Rust (v0.7.26)

Перепись Python-версии на Rust: авто-подсчёт времени игр/программ,
защита от ложных срабатываний лаунчера через нагрузку на видеокарту.

Запуск: `cargo run --release` или `target\release\game-session-tracker.exe`.
Проверка: `cargo test` (61 юнит-тест: шорткаты, дни будильников, масштаб,
мониторы, иконки, поля страницы, вёрстка мини-трея, разворачивание окна,
контраст и геометрия оформления).
Живая проверка мониторов этой машины:
`cargo test live_monitor_report -- --ignored --nocapture`.

## Готовые сборки

В репозитории лежат собранные файлы последней версии — их можно скачать
прямо с GitHub, собирать Rust не нужно:

- `TraySession.exe` — сама программа (запуск из корня проекта);
- `Tray_sesstion_setup.exe` — установщик 7-Zip SFX, имя именно такое
  (опечатка в названии сделана намеренно, чтобы не спутать файл).

Полный список изменений — в разделе «О программе» внутри программы
(константа `CHANGELOG` в `src/app.rs`), история не сокращается.

## Горячие клавиши

Умолчания: `Alt+1…Alt+7` — вкладки; `Ctrl+}` — быстрый будильник
(разовый, звук BEEP); `Ctrl+{` — быстрый таймер (минуты 1–999, Enter —
старт); `Ctrl+E` — экспорт CSV; `Ctrl+R` — обновить; `Esc` — закрыть
диалог; `Ctrl+H` — в трей. Вкладка «Управление»: переназначение любых
шорткатов (включая Mouse4/Mouse5), автосохранение в `shortcuts.json`;
документация показывает текущие шорткаты сама.

## Главная логика (авто-трекинг)

`src/monitor.rs` + `src/gpu.rs`:

1. Каждые N сек (по умолч. 10) сверяем живые процессы с вашим списком игр
   (точное совпадение пути + fallback по имени exe — переживает переезд
   библиотеки на другой диск).
2. Каждый кандидат проверяем в NVML (`running_graphics_processes` +
   `running_compute_processes`):
   - PID есть в GPU-списке → это реально рендерящая игра;
   - PID нет → это лаунчер (Steam/EGS/HoYoPlay) или фон → игнорируем.
3. На Linux дополнительно требуем VRAM ≥ порога (по умолч. 80 МБ).
   На Windows (WDDM) драйвер байты не отдаёт — доверяем факту присутствия
   PID в списке (поле `vram_unknown`).
4. Без NVML (AMD/Intel) — fallback: CPU ≥ порога (3%) или RAM ≥ порога (250 МБ).
5. Старт после `confirm_hits` подряд активных опросов (анти-дребезг),
   завершение после `grace_secs` тишины (по умолч. 10 сек).
6. Таблица «Сессии» обновляется автоматически (события Started/Ended +
   refresh каждые 3 сек), активные помечены ●.

## Что перенесено из Python-версии

- Сессии: сводная таблица (№, игра, общее время, % от общего, запускал, сессий),
  детали по игре с разделителями по суткам, редактирование длительности,
  удаление, экспорт CSV.
- Активные: живой список с CPU/RAM/VRAM/GPU и elapsed.
- Игры: скан Steam (все библиотеки из `libraryfolders.vdf` → манифесты
  `appmanifest_*.acf` → имя + `installdir` → самый большой exe без редистов/
  лаунчеров; проверено живьём: 39 игр за 0.9 с), скан реестра
  Windows, Steam Web API, ручное добавление, **указание папки с игрой**
  (топ exe по размеру), **выбор из активных процессов с поиском**.
- Настройки GPU-гейта: требовать GPU, пороги VRAM/CPU/RAM, интервал опроса,
  grace period, подтверждения, начало игровых суток, автоскан каждый час.
- Будильники: время и дни меняются кнопкой «Изменить» в любой момент
  (в т.ч. для неактивных); у каждого активного — живой обратный отсчёт
  ч:м:с; дни недели — галочки Пн–Вс или пресеты «Будни»/«Выходные»/
  «Ежедневно»/«Разовый»; активный будильник — на аналоговых часах
  НИЖЕ списка (таблица и кнопки всегда на месте), остальные рядом
  цифровой колонкой.
- Таймер (пресеты + свой, URL/звук), диалог snooze +10 мин;
  у активного таймера — аналоговый циферблат.
- Секундомер: старт, пауза, стоп, круг, сброс; PIN от перетаскивания;
  окошко-минимум без рамок поверх всех окон (таскается за фон 1:1,
  размер — курсором за край, контент зумится), цифры +20% с тысячными,
  дубли последних 3 кругов, прозрачность 2–100% (Ctrl+Num+/Num− когда Pinned).
  Кнопка ⤢ разворачивает окошко почти вдвое и добавляет таймер обратного
  отсчёта (пресеты 1/5/10/30 мин, стоп, полоска хода) — тот же, что на
  вкладке «Таймер».
- Глобальные хоткеи (RegisterHotKey, правый Shift отдельно): RShift+↑ старт/пауза,
  RShift+→ круг, RShift+← стоп, RShift+↓ Pin — работают поверх игры, пока
  окошко открыто; шорткаты — во вкладке «Параметры».
- Мини-трей (стиль uTorrent, вкладка «Сессии»): одна тонкая линия 30 px на
  позиции 3×3 выбранного монитора (где полоска или курсор, хоть 6–8K).
  Показывает только идущую запись текущей сессии: название игры и время
  (зелёным), при ожидании GPU-гейта — приглушённо. Полная история — в
  таблице сессий. Место запоминается и зажимается внутрь рабочей области,
  окно не выходит за границы экрана даже после смены разрешения. Пока
  полоска поверх всех окон, управление с клавиатуры: RShift+←/→ позиция
  3×3, RShift+↑/↓ прозрачность ±5%.
- Плавающие окошки **нельзя свернуть** (снят WS_MINIMIZEBOX): Win+D,
  двойной клик по таскбару и Aero Snap их не убирают, а если окно всё же
  свернули сторонней программой — оно возвращается на экран само.
  Спрятать окошко = снизить прозрачность (Ctrl+Num± или ползунок).
  Стиль окна правится один раз при создании: вносить его каждый кадр нельзя,
  winit переустанавливает стиль сам, и постоянная борьба ломает окно.
- Автопоправка позиции срабатывает только если окно потеряно ЦЕЛИКОМ
  (не пересекается ни с одним монитором). Окно, прижатое пользователем к
  краю, не трогается.
- Тема интерфейса в цветах клиента Steam (фон #1B2838, акцент #66C0F4).
- Трей: иконка живёт в потоке с Win32 message pump — тултип при
  наведении, меню Открыть/Выход, открытие кликом; крестик = скрыть в трей.
- Боковая навигация с иконками из `assets/` (6 PNG 64×64, красятся в цвет
  состояния кнопки).
- Все блоки разделов выровнены по одной ширине: поля 5% окна симметрично
  слева и справа (8–60 pt), поэтому вёрстка одинакова на 1080p и 6–8K.
  Заголовки и пояснения разделов стоят на одной вертикали с карточками,
  таблицы занимают всю ширину карточки и не выходят за её границы.
- Клик по версии внизу сайдбара открывает раздел «О программе» и сразу
  запускает проверку обновлений (сейчас — доступность GitHub). Отдельного
  окна нет.
- Вид: «Масштаб» во вкладке «Параметры», сохраняется
  в `config.json` (`ui_scale`) — для читаемости на больших мониторах.
  100% на шкале = базовый масштаб 1.3 (бывшие 130%).
  Ползунок правит черновик и применяется после отпускания (окно не
  «уезжает» из-под курсора); шаги — кнопками −/+, сброс — 100%.
  Ряды кнопок переносятся на следующую строку, вкладки прокручиваются —
  на большом масштабе кнопки не пропадают за краем окна.
- Производительность: перерисовка по требованию (в простое CPU ~0),
  кэш хэндла NVML на поток, список процессов без заморозки UI,
  таблица сессий обновляется по событиям.
- Трей: иконка, меню Открыть/Выход, тултип с активными сессиями,
  уведомления о старте/конце/утренней сводке. Крестик = скрыть в трей.
  «Открыть окно» поднимает и **свёрнутое** окно и выводит его поверх
  остальных (одной команды видимости мало: у свёрнутого окна Windows
  держит отдельный флаг минимизации).
- Иконка программы своя — скруглённый квадрат #66C0F4 с белым
  play-треугольником; одна и та же картинка в трее и в заголовке окна.
- Вкладка «О программе»: 1) о программе (Tray Session, версия, сборка),
  2) документация, 3) «Сообщить о проблеме» (ссылка позже).
- Игровые сутки с 03:00, как в оригинале.

## Настройки

Хранятся в `config.json` рядом с exe:

```json
{
  "api_key": "...",
  "steam_id": "...",
  "check_interval_secs": 10,
  "grace_secs": 10,
  "day_start_hour": 3,
  "require_gpu": true,
  "min_vram_mb": 80,
  "min_cpu_pct": 3.0,
  "min_ram_mb": 250,
  "confirm_hits": 1,
  "auto_scan_enabled": true,
  "ui_scale": 1.0
}
```

## Структура

- `src/main.rs` — точка входа, трей-поток, запуск eframe.
- `src/app.rs` — весь UI (egui): вкладки, диалоги, экспорт, алармы, таймер.
- `src/monitor.rs` — фоновый поток опроса процессов + GPU-гейт.
- `src/gpu.rs` — опрос NVML.
- `src/detector.rs` — Steam/реестр/папка/процессы/Steam API.
- `src/db.rs` — SQLite (`sessions`, `alarms`).
- `src/config.rs` — конфиги, `known_games.json`, игровые сутки.
- `src/sound.rs` — системный beep-повтор + открытие URL/файлов.

## Зависимости

eframe/egui, rusqlite (bundled), sysinfo, nvml-wrapper, winreg,
reqwest (blocking, Steam API), csv, open, rfd, notify-rust, tray-icon, winapi.

## Проверка оформления

Окно рисуется через GPU, поэтому снимок экрана средствами Windows
(`PrintWindow`) получается чёрным — оценить цвета и иконки на глаз нечем.
Для этого есть превью: те же элементы рисуются теми же средствами egui.

```
cargo test -- --ignored
```

Файлы: `target/ui_preview.png` (кнопки во всех состояниях, иконки, чипы) и
`target/nav_icons_preview.png` (иконки разделов крупно, поверх сетки 24dp).

Параллельно контраст считается числами, а не «на глаз». Функция
`contrast_ratio` реализует WCAG 2.1; тесты `button_contrast_meets_wcag` и
`nav_button_text_contrast_in_all_states` требуют не меньше 4.5:1 во всех
состояниях кнопок, а `nav_press_effect_is_strong_enough_to_see` следит,
чтобы эффект нажатия не стал неразличимым.

Иконки разделов заданы вектором в сетке 24dp (`nav_icon_shapes`) и красятся
цветом состояния кнопки. Тесты `nav_icons_fit_their_cell`,
`nav_icons_are_outline_style` и `nav_icons_have_no_degenerate_geometry`
проверяют геометрию: иконка не вылезает за клетку, не превращается в
глухую заливку и не схлопывается в точку.
