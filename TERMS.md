# Условия использования Tray Session

Программа предоставляется «как есть». Автор не несёт ответственности:

- за потерю данных (sessions.db, config.json, known_games.json,
  shortcuts.json) — делайте резервные копии;
- за работу на неподдерживаемых конфигурациях (не-Windows,
  экзотические DPI, отключённые мониторы);
- за сбои при обновлении (в beta-версиях, в том числе).

Программа собирает только локальные данные. Никакие данные не
отправляются на серверы автора. Сетевые запросы: Steam Web API
(по вашему API-ключу), GitHub (проверка обновлений).

Распространение и модификация без письменного разрешения автора
запрещены (см. LICENSE).
