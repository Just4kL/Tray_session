# Иконки интерфейса

Файлы `.rgba` подготовлены из набора `F:\Programms\Assetst icons` и встроены в приложение через `include_bytes!`.

Навигационные иконки имеют размер 48×48 пикселей, значок приложения — 32×32. Формат файлов: RGBA8, строки идут сверху вниз, пиксели в каждой строке — слева направо.
