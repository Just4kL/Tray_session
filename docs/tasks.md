## CRITICAL — баги, не связанные с UI-рефакторингом

### C1. Оверлей секундомера/таймера пропадает, PIN не помогает
**Симптом:** оверлей пропадает; кнопка «поверх окон» не делает окно видимым;
PIN не помогает.
**Не от 1.2.a.4** — проверить на `pre-ui-refactor`, скорее всего pre-existing.
**Контекст:** `app.rs::show_stopwatch_overlay`, `place_overlay_on_saved_mon`,
`apply_overlay_opacity`, `ensure_thickframe` (WinAPI `SetWindowLongW`/
`SetWindowPos`).
**Гипотеза:** потерян `WS_EX_TOPMOST`; либо `SetWindowPos` вызывается без
`HWND_TOPMOST`; либо `place_overlay_on_saved_mon` сбрасывает topmost каждый
кадр; либо ex-style меняется без `SWP_FRAMECHANGED`.
**Оценка:** 1–2 часа.
**Тест:** программный — проверить, что после `place_overlay_on_saved_mon`
флаг `WS_EX_TOPMOST` установлен (через `GetWindowLongW`).

### C2. Первый клик не захватывает borderless-окно
**Симптом:** первый drag по мини-трею или оверлею не захватывает окно;
работает только со второй попытки.
**Контекст:** `overlay_window_style`, `ensure_thickframe`, обработка
`WM_NCHITTEST` / `WM_NCLBUTTONDOWN`.
**Гипотеза:** на первом клике окно неактивно → Windows проглатывает
`HTCAPTION` и активирует окно вместо drag. Классика для borderless без
`WS_EX_NOACTIVATE`.
**Оценка:** 1–2 часа.
**Тест:** ручной (двойной click-drag).

(секция «Таймер» — кнопки в хаосе, UPDATE огромная и не на месте).
**Цель:**

**Проверка:** разрешения 800×600 → 4K × 2 скина, отсутствие наложений.
**Зависимости:** нет.

## DESIGN — после engine (запрос пользователя 2026-10-01)

### D1. Единый визуальный стиль

**Референсы:** `docs/design_reference/comfyui-topbar.png`,
`docs/design_reference/comfyui-update-dialog.png`,
`docs/design_reference/comfyui-updating.png`,
`docs/design_reference/comfyui-update-view.png`.

- **Верхняя панель** (`comfyui-topbar.png`):
  * пилюля «Tray Session [Update] ▾» — бренд + действие + dropdown
    в одной капсуле, тонкая обводка, нейтральный фон;
  * рядом статус-пилюли (жёлтая — обводкой, не заливкой);
  * набор системных иконок 16×16 в один ряд с «свернуть/развернуть/закрыть».

- **Кнопка UPDATE** — пилюля рядом с версией, не заливка.
  Жёлтый — только обводка + иконка. См. `comfyui-update-view.png`
  (зелёный бейдж `Up to date` рядом с версией).

- **Диалоги** (`comfyui-update-dialog.png`): карточка с заголовком,
  телом, двумя действиями (нейтральное + акцентное).
  Радиус ~8px, тень, заголовок 15–16pt semi-bold.

- **Окно обновления** (`comfyui-update-view.png`):
  * верхний блок: текущая версия + бейдж состояния (актуально /
    доступно обновление / проверка);
  * список модулей/компонентов с версиями и muted-подписями выбора;
  * выбор канала/ветки — dropdown с пояснением под ним;
  * кнопки «Проверить обновления» (нейтральная) и primary action
    (Restart/Update) — в одной нижней полосе.

- **Состояния процесса** (`comfyui-updating.png`):
  * центральная зона → полноэкранное состояние: заголовок действия,
    muted-подпись, текущий шаг, тонкий прогресс-бар;
  * никаких модальных блокировок окна;
  * кнопки, не относящиеся к процессу, остаются активными
    (не greyed-out), чтобы не выглядело «зависшим»;
  * правый-нижний блок — статус/переключатель, во время процесса
    показывает заглушку «Switch».

- **Общее:** иконки 16×16, без подписей, с tooltip. Кнопки в одной
  плоскости с системными.

**Связь с H2:** индикатор процесса в статус-баре — упрощённая форма
того же состояния для случаев, когда операция не занимает весь экран.

### D2. Визуальные разделители, сетка текста
Единые отступы, заголовки одного веса, разделители между блоками.
Часть `tokens.spacing`, выведенная в `LayoutSpec`.
**Зависимости:** H1.

## Правила гигиены (инциденты, вошедшие в бриф)

- **Тег после коммита, не до.** Порядок: commit → status пусто → tag → push
  ветки → push тега. Инцидент 2026-10-01: тег дважды ушёл на устаревший хеш.
- **Amend только до пуша.** Если коммит уже запушен или тегирован — не
  амендить, обновления идут следующим коммитом.
- **Скоуп фиксируется явно** — что трогать и что НЕ трогать.
- **Тесты не править под код** — код править под тесты.
